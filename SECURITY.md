# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 1.x     | ✅        |

## Reporting a vulnerability

If you discover a security vulnerability, please **do not** open a public issue. Instead, report it privately:

1. Open a [private security advisory](https://github.com/0x-Shadow/folio/security/advisories/new), or
2. Contact the maintainer at [@0x-Shadow](https://github.com/0x-Shadow).

Please include a description of the issue, steps to reproduce, and the potential impact. You can expect an initial response within 7 days.

## Scope notes

Folio is a static front-end app with no backend, authentication, or secrets. There are no API keys or credentials in this repository — please keep it that way and never commit `.env` files.
